## Purpose

Teach learners how budget information is organized — the documents, classifications, and spending vocabulary needed to read any budget figure intelligently.

## Learning objectives

After this module, the learner can:

1. Distinguish the NEP, GAA, and BESF by what each document is and when it appears.
2. Explain how the budget is organized by agency, program/activity/project, and expense class.
3. Name the four expense classes and give an example of each.
4. Trace the meaning chain appropriation → allotment → obligation → disbursement → expenditure.
5. Distinguish current from continuing appropriations.

## Lessons

### 03.1 The Three Core Documents

* Guiding question: If the budget were a library, what are the three books everyone cites?
* Concepts: NEP (executive's proposal), GAA (the enacted law), BESF (expenditures and financing side-by-side); how they relate chronologically
* Interactive or visual: three-document lifecycle diagram (NEP → GAA → execution reports, BESF alongside)
* Worked example: none
* Activity and knowledge check: given a question ("How much did Congress approve for X?"), pick the right document; 3-item check

### 03.2 How a Budget Line Is Built

* Guiding question: What exactly is a "budget line"?
* Concepts: agency → program → activity/project hierarchy; special-purpose funds; organizational, sectoral, geographic, funding-source classifications — same money, four lenses
* Interactive or visual: drill-down tree of a real agency budget (simplified)
* Worked example: none
* Activity and knowledge check: place a sample line item in the hierarchy; 2-item check

### 03.3 The Four Expense Classes

* Guiding question: Why do budgets separate salaries from buildings?
* Concepts: Personnel Services; MOOE; Financial Expenses; Capital Outlays; what each buys and why the separation matters (e.g., PS caps, capital vs recurring)
* Interactive or visual: int-02 annotated budget entry (hotspots)
* Worked example: none
* Activity and knowledge check: int-02 identification task is the check; plus 2-item classification check

### 03.4 From Authority to Spending

* Guiding question: Is an appropriation the same as money in the bank?
* Concepts: appropriation → allotment → obligation → disbursement → expenditure chain (preview: full mechanics in Module 5); current vs continuing appropriations (one-year vs two-year validity periods)
* Interactive or visual: five-stage pipeline visual with a peso coin traveling through
* Worked example: none
* Activity and knowledge check: order-the-stages sequencing activity; 2-item check

## Interactive element

* **int-02 Annotated budget entry:** hotspot annotator over a simplified replica GAA/NEP entry; clicking each region (agency, program, expense class, amount, special provision) reveals what it is and why it matters. Static replica, illustrative figures. Fallback: fully labeled static diagram of the same entry.

## Assessment

Module check: 6 items covering documents, hierarchy, expense classes, and the spending-stage chain.

## Worked examples used

None as narratives; this module is structural. Simplified document replicas serve as worked examples.

## Sourcing notes

Expense-class detail and classification systems need DBM references (GAA structure, UACS classifications). Replica entries must be clearly labeled as simplified illustrations, not facsimiles of official documents.
