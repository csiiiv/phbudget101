## Purpose

Develop practical budget literacy: knowing which document answers which question, and reading figures, tables, and provisions accurately.

## Learning objectives

After this module, the learner can:

1. Match common budget questions to the right document (NEP, GAA, BESF, execution reports, audit reports, local documents).
2. Read a budget table: classifications, footnotes, and special provisions.
3. Distinguish nominal from real values and know when each is appropriate.
4. Track an amount across its life: proposed → approved → released → obligated → disbursed.
5. Compare budgets responsibly: year-on-year, per-capita, geographic.
6. Name the common analytical mistakes and data limitations that trip up new analysts.

## Lessons

### 07.1 The Right Document for the Question

* Guiding question: I want to know how much was actually spent on X — which document do I open?
* Concepts: document-to-question mapping across NEP, GAA, BESF, agency documents, execution reports (SAODB, SNCA, disbursement reports), COA audit reports, local budget documents; "publicly reported" vs "real-time per-project" limits
* Interactive or visual: document selector decision tree
* Worked example: none
* Activity and knowledge check: question → document matching drill; 3-item check

### 07.2 Reading the Fine Print

* Guiding question: Why does one footnote change the meaning of a whole table?
* Concepts: table anatomy (rows, columns, groupings); classifications as lenses; footnotes and general/special provisions; where "the money is only part of the story" lives
* Interactive or visual: annotated table excerpt (reuses int-02 hotspot component)
* Worked example: none
* Activity and knowledge check: find-the-provision search task; 2-item check

### 07.3 Comparing Amounts Honestly

* Guiding question: Is a 10% budget increase actually an increase?
* Concepts: nominal vs real values (inflation); proposed/approved/released/obligated/disbursed as different numbers; year-on-year comparison pitfalls (realignments, renaming, mergers); per-capita and geographic normalization
* Interactive or visual: nominal-vs-real toggle chart
* Toggle note: data static and dated
* Worked example: none
* Activity and knowledge check: spot-the-misleading-comparison scenarios; 3-item check

### 07.4 Avalanches and Increments

* Guiding question: How do you find the story hiding in a thousand-line budget?
* Concepts: the avalanche/increment method from the guidebook — scanning for unusually large increases, decreases, and items appearing/disappearing across years; building year-series; what each pattern suggests
* Interactive or visual: avalanche-spotting exercise on a simplified two-year comparison table
* Worked example: active-transport budget items again (from 04.1) — how a year-over-year comparison of transport lines reveals the items that grew, shrank, appeared, and disappeared; the Move As One coalition named per the factual-event exception (ADR-008 amended 2026-08)
* Activity and knowledge check: mark the avalanches in a sample table; 2-item check

## Assessment

Module check: 6 items — document mapping, provision interpretation, nominal/real, and comparison hygiene.

## Worked examples used

Active-transport budget items (07.4): the year-series of transport budget lines is public record, making it the natural neutral dataset for avalanche spotting. It deliberately reuses the 04.1 items so learners see the same money twice — first as a preparation-phase story, then as an analysis exercise.

## Sourcing notes
