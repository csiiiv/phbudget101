# Supporting Reference Section — Spec

The reference section is a separate area from the learning path: lessons link into it, and it never depends on lesson order. It serves the topic-based path, quick lookups during the course, and post-course use as a standalone resource.

| Field | Value |
| --- | --- |
| Status | outline |
| Build phase | 1 (core pages); 2 (search) |
| Prerequisites | none |
| Sourcing | seed from guidebook glossary + annexes; extend per component spec |

## Editorial rules

Inherits all build-spec conventions. Two additional rules:

* **Neutrality rule applies in full** — but this is where source attribution lives: the sources page credits the guidebook and its referenced materials; glossary/acronym entries may cite DBM/DOF/COA glossaries.
* **Self-contained entries** — every page must make sense to a reader who arrives via search without having taken any module. No "as we saw in Module N" without restating the needed context.

## Components

### ref-01 Glossary

* **Purpose:** single source of truth for definitions (per build-spec terminology rule).
* **Seed:** ~60 terms from the guidebook glossary (pp. 110–115): budget-cycle stages, spending-stage terms (allotment, obligation, SARO, NCA, disbursement), documents (NEP, GAA, BESF, PBM), institutions (DBM, DBCC, NEDA, COA, BTr), local PFM (LCE, LGU, NTA, LDC), and advocacy-method terms (problem owners, policy analysis, secretariat, CSW).
* **Extend:** terms introduced by course content not in the seed (fiscal space, expense classes, continuing appropriations, avalanche/increment, outputs vs outcomes, PS/MOOE/CO/FE, GPPB, UACS, transparency seal).
* **Entry shape:** term; short definition (≤2 sentences); "used in" links to modules; optional cross-reference to related terms; source tag (guidebook, DBM, etc.).
* **Notes:** guidebook entries need verification against current official definitions (some read informal, e.g., "plantilla"); the DBM glossary the guidebook itself cites is the authority for national-budget terms. The guidebook's "tarabangan" entry is dropped (case-specific).
* **Phase 1:** alphabetical page + per-term anchors.

### ref-02 Budget document library

* **Purpose:** one entry per budget document, answering "what is it, when does it appear, what's in it, where do I find the real thing."
* **Seed:** the guidebook's document list (Chapter 3 / Annex 1): BRF, PBM, NEP, GAB, GAA (+ veto message), BESF, and the execution-report set (SAODB, SNCA, disbursement reports).
* **Extend:** agency budget proposals, COA annual audit reports, local documents (AIP, local budget matrix), Transparency Seal disclosures.
* **Entry shape:** name and acronym; phase(s) of the cycle it belongs to; what questions it answers; where published (official portal + section); simplification note when the course uses replicas.
* **Phase 1:** document list page with per-document detail.

### ref-03 Institutional map

* **Purpose:** who's who across the budget cycle — the permanent reference backing Modules 4, 6, and 9.
* **Seed:** institutions already in module specs: DBM, DBCC, DOF, NEDA, BTr, BIR, COA, House/Senate (committee structure), President/veto, bicam; local side: LCE, sanggunian, LDC, special bodies, DILG review.
* **Extend:** GPPB (procurement), PSA (data), civil-service/oversight bodies as needed by content.
* **Entry shape:** institution; role per cycle phase; key documents it produces; official site link.
* **Phase 1:** grouped page (national executive / legislative / oversight / local).

### ref-04 Budget calendar

* **Purpose:** when things happen — the static, always-current-when-dated reference for cycle timing.
* **Seed:** phase-level timing from guidebook Annex 1 (e.g., budget call ~Dec, NEP submission ~Aug of prior year).
* **Extend:** typical committee schedule, bicam timing, GAA effectivity, execution-report cadence; local calendar alongside national.
* **Entry shape:** month-by-month table; separate national and local columns; "varies by year" annotations; last-verified date on every row.
* **Phase 1:** static table, clearly dated.

### ref-05 Classification reference

* **Purpose:** the structure behind budget tables — reference for Modules 3 and 7.
* **Seed:** expense classes (PS/MOOE/FE/CO); agency→program→activity/project hierarchy; organizational/sectoral/geographic/funding-source classifications.
* **Extend:** UACS code structure (code segments and what each means) — concept-level, sourced from DBM/UACS documentation.
* **Entry shape:** classification system; segments/levels; worked example of classifying one line item multiple ways.
* **Phase 1:** static page with examples.

### ref-05b Local government budget structures

* **Purpose:** local-side reference for Module 6 — the local documents, review chain, and statutory constraints that don't belong in lesson flow.
* **Seed:** local budget sequence and review chain from guidebook Chapter 2 (executive preparation → sanggunian authorization → review).
* **Extend:** the 5% statutory caps context, the 20% development fund, 45% PS cap, debt-service rules, barangay vs municipal vs provincial structure.
* **Entry shape:** short explainer + constraints table with legal basis (LGC sections).
* **Phase 1:** static page.
* **Note:** added as a new component during spec review; numbering continues from ref-05.

### ref-06 Acronyms

* **Purpose:** one-stop expansion of every acronym used anywhere in the course.
* **Seed:** all acronyms from the glossary seed list plus module specs (NEP, GAA, BESF, PBM, BRF, GAB, NTA, IRA, LCE, LDC, SARO, NCA, SAODB, SNCA, MFO, UACS, GPPB, TRAIN, PPP, CSW, MOOE, PS, CO, FE).
* **Extend:** whatever authoring introduces; the page mirrors the glossary (one-way sync: acronym → glossary term entry).
* **Entry shape:** acronym; expansion; link to glossary entry.
* **Phase 1:** single alphabetical page.

### ref-07 Legal and policy references

* **Philippine Constitution provisions on appropriation (Art. VI Sec. 29 etc.)** — the "no money shall be paid out" principle.
* **Administrative Code of 1987** — budget execution authority framework.
* **Local Government Code of 1991 (RA 7160)** — local budgeting, NTA/IRA, local bodies.
* **GAAs and budget process reform laws** — including budget modernization acts (e.g., RA 10717 Modified GAA documentation, cash budgeting era laws); verify exact acts at authoring.
* **Sin Tax Reform Law (RA 10351)** and **TRAIN (RA 10963)** — revenue-side worked examples.
* **Government Procurement Reform Law (RA 9184)** — procurement references for Module 5.
* **Entry shape:** law/issuance; what it governs; sections relevant to the course; official source link (Official Gazette, DBM, Supreme Court E-Library).
* **Phase 1:** static page; laws only, no commentary.

### ref-07b Sources and attribution

* **Purpose:** the neutrality rule's designated home for named attribution — guidebook, partner organizations, and referenced works live here, never in lessons.
* **Seed:** the guidebook's references list (pp. 116–122) — domestic budget literature (Abante transport budget analyses, CSW modules, coalition guidebook, YBL working papers) + DBM/DOF/COA/PSA official sources used by the course.
* **Entry shape:** full citations; scope note ("budget campaign materials listed as sources of methods and public facts"); no annotation implying endorsement.
* **Phase 1:** static page.
* **Note:** the neutrality rule explicitly routes organization names here.

### ref-08 Data-source directory

* **Purpose:** where the numbers live — every public dataset the course cites or learners may use.
* **Seed:** DBM (NEP, GAA, execution reports, Transparency Seals), DBCC fiscal reports, COA audit reports and Citizens' Guides, DOF/BTr debt and cash data, PSA (CPI, population for per-capita work), OpenTendering/PhilGEPS for procurement.
* **Entry shape:** dataset/portal; what it contains; update cadence; coverage start; direct link; caution notes (lags, breaks in series).
* **Phase 1:** static directory grouped by topic.

### ref-09 FAQ

* **Purpose:** the questions a general audience actually asks, answered in plain language with links into glossary/lessons.
* **Seed questions:** What's the difference between the budget and the GAA? Why is the budget for next year debated this year? Is the NEP already law? What happens if the budget is late? Can I see how much went to my barangay? What can I do if I disagree with a budget decision? Where do I report suspicious spending?
* **Extend:** from real learner questions post-launch; maintain a living FAQ backlog.
* **Entry shape:** question; 2–4 sentence answer; links.
* **Phase 1:** static page.

### ref-10 Search

* **Purpose:** findability across glossary, documents, institutions, calendar, FAQ.
* **Phase 2:** client-side index over ref pages (static site search); no server dependency.
* **Phase 1 fallback:** none — browser find on well-structured pages.

## Data currency and maintenance

All time-sensitive entries (calendar, data sources, legal references) carry a "last verified" date. Owner and cadence defined at content phase; MVP assumes a yearly review pass timed to the national budget season (August–December), when documents and dates churn.

## Open questions
